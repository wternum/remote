## 一、证据分级：什么叫"可证实"

"可证实"不是"很多人这么说"，而是**存在独立于当事人叙述的记录**。

| 级别 | 证据类型 | 强度 | 本案代表 |
| --- | --- | --- | --- |
| **T1** | 法律强制公开的财务记录 | 最强，且**亏损也会公开** | Kullamägi（瑞典公开税单） |
| **T2** | 主流媒体核查原始凭证后报道 | 强，媒体有声誉成本 | Zanger（Fortune 查税单）、Darvas（Time 四次核查） |
| **T3** | 监管/交易所官方文件、赛事审计 | 强，但只覆盖片段 | BNF（大额持股申报）、Larry Williams（Robbins 赛事） |
| **T4** | 第三方平台逐笔追踪 | 中，存在商业利益关联 | Grittani（Profit.ly） |
| **T5** | 自述 + 截图 | 弱，不收录 | — |

**关键原则**：T1 之所以最强，是因为**它同时记录了失败**。Kullamägi 的 2022 年巨亏和他的盈利一样是公开记录 —— 这正是可信度的来源。只公开盈利、不公开亏损的记录，无论多详细都要降级。

## 二、五个可证实案例与完整交易方式

### 2.1 Kristjan Kullamägi（Qullamaggie）— T1，证据最强

**资金曲线**（约 $5,000 → 峰值 $105M）：

| 时间 | 账户 | 发生了什么 |
| --- | --- | --- |
| 2011 春 | ~$5,000 | 保安打工攒的钱，第一个账户 |
| 2011–2013 | **爆仓 3 次** | 分别撑了 2 个月、5 个月、近 1 年 |
| 2013-05 | $9,100 | 第四次尝试，开始盈利 |
| 2014-01 | $43,000 | |
| 2017 末 | $1M | |
| 2020-01 | $3.5M | |
| 2020-12 | $36M | 单年约 +1,000% |
| 2021-11 | **$105M** | 最后一段 $65M→$105M 只用了约 6 周 |
| 2022 中 | ~$45M | **回吐约 $60M** |

**公开税单记录**（瑞典税单属公共记录，按当年平均汇率折美元）：

| 年份 | 已实现交易所得 |
| --- | --- |
| 2014 | $353K |
| 2015 | $261K |
| 2016 | $457K |
| 2017 | $1.5M |
| 2018 | $1.2M |
| 2019 | $1.2M |
| **2020** | **$33M** |
| **2021** | **$42M** |
| **2022** | **−$26M** |
| 2014–2021 累计 | **$80M** |
| 累计纳税 | **$24M** |

> 注意：他每年都从账户**取出资金**缴税和生活，所以复利是**扣除真实拖累后**的结果，不是封闭账户里的理论数字。

#### 他的三个交易方式（完全免费公开，无付费课程）

**① Breakout（整理突破）— 主力打法**

| 项目 | 规则 |
| --- | --- |
| 选股池 | 过去 **1/3/6 个月涨幅前 1–2%** 的股票 |
| 形态 | **1–3 周**的紧凑整理，价格"贴着"上升的 10/20/50 日均线走 |
| 前置涨幅 | 通常已在 12 周内涨过 30–100% |
| 触发 | 突破整理区间高点，**成交量放大确认** |
| 止损 | **突破当日最低点** |
| 持有 | 3–5 天，剩余仓位用 10/20 日均线移动止损 |
| 减仓 | 入场后 3–5 天先卖 1/3 到 1/2，止损移到保本 |

**② Episodic Pivot（EP，事件驱动跳空）— 他后期最偏爱的**

| 项目 | 规则 |
| --- | --- |
| 触发 | 财报/新闻导致**跳空 ≥10%**，开盘巨量（理想是前 15–20 分钟就达到日均量） |
| 入场 | 等价格突破**开盘区间高点**（1 分钟或 5 分钟），不猜 |
| 止损 | 当日低点 |
| 持有 | 数日到数周 |
| 增强条件 | EPS 超预期越大越好；**此前被市场冷落、股价阴跌的股票效果更好**（ surprise 更强） |

> EP 的学术基础是 **PEAD（盈余公告后漂移）**：Ball & Brown 在 1960 年代发现，股价会在财报意外后**持续同向漂移数月**。这不是图形玄学，是有文献的现象。

**③ Parabolic Short（抛物线做空）**

| 项目 | 规则 |
| --- | --- |
| 标的 | 小盘拉高出货股 |
| 触发 | **3–4 天累计涨幅 300%+** 后出现走弱 |
| 止损 | 当日高点 |
| 持有 | 数天 |

#### 风险与执行

- **单笔风险 0.5%，最多 1%**
- **自述胜率 25–30%** —— 即 10 笔里 7–8 笔亏钱
- 靠少数大赢家的赔率覆盖全部小亏损
- **80% 的交易发生在开盘后前 20% 的时间**
- 有**市场环境过滤器**：大盘在 10/20 日均线之下就转现金

#### 2022 年为什么亏 $60M

他自己的趋势指标在 2021 年底已经转向，**但他忽略了自己的规则**，在下跌趋势中继续做突破和 EP。他本人估计：**只要遵守那一条均线过滤规则，就能避免 90% 的损失。**

**这条教训比任何入场技巧都重要。**

### 2.2 Dan Zanger — T2，Fortune 核查过税单

**记录**：$10,775 → $18,000,000（1998-06 至 1999-12，约 18 个月），后续推至约 $42–43M（23 个月）。

**验证方式**：《Fortune》杂志在报道前**审查了他的 IRS 报税记录和交易记录**；另有资产管理机构 Effron Enterprises 参与核验。这是少见的主流媒体查原始凭证的案例。

**资金来源**：他卖掉了自己的保时捷，约 $11,000。

**⚠️ 同样重要的后续**：互联网泡沫破裂后，他**回撤约 87%**，加上缴税与后续挫折，账户回落到约 $7M。

#### 他的十条规则（公开）

1. 确保股票有**成形的底部或形态**（旗形、杯柄、平台、上升三角形）。
2. 当价格**突破该形态的趋势线**时买入，且突破后不久**成交量要高于近期水平**。**追价不超过趋势线上方 5%**。要知道该股的 **30 日均量**。
3. 若股价**回落至突破点下方 $3–5**，迅速卖出。
4. （原文档此条略）
5. **最强的股票持有最久**；停止上涨或走势迟滞的迅速卖出。
6. 识别并跟随**强势板块**，选股尽量落在这些板块内。
7. 市场大幅运行一段时间后，持股会变得脆弱，抛售可能又快又猛。学会**画新的更高趋势线**、识别反转形态来帮助离场。
10. **在未掌握市场、图表与自己的情绪之前，绝不用融资**。融资能让你归零。

> **明显的内在矛盾**：第 10 条告诫别用融资，但他自己 1999 年的收益恰恰**大量依赖融资**。这不否定规则，而是说明**他把"已掌握"的门槛设得极高**，且承担了 87% 回撤的后果。

### 2.3 Takashi Kotegawa（BNF）— T3，官方披露可查

**记录**：约 ¥1.6M（约 $13,600）→ 约 ¥18–20B（约 $150M），约 8 年。

**验证方式**：
- 日本财务省**大额持股申报**中出现其真实姓名（这是法定披露）
- 2005 年 **J-Com 事件**有交易所特别清算记录
- 东京电视台专题节目实地拍摄

#### 他的实际交易方式：短期均值回归

| 项目 | 规则 |
| --- | --- |
| 标的 | **高流动性**大盘股（钢铁、造船等板块） |
| 触发 | 股价**低于 25 日均线约 20–35%**（严重超跌） |
| 持有 | **2–6 天** —— 注意：媒体常称他为"日内交易员"，实际更接近**短期波段** |
| 核心 | 严格风控，等极端偏离才出手 |

**他的原话（电视采访）**：
> "我不知道日本股市的未来。我不从长期视角看市场。"

#### 必须澄清的两点

**① J-Com 事件不是策略，是别人的操作失误。**
2005 年 12 月，瑞穗证券交易员把"以 ¥1 卖 672,000 股"错输成"以 ¥672,000 卖 1 股"。BNF 买入 7,100 股，当日卖出 1,100 股，剩余 6,000 股通过特别清算以 ¥912,000/股了结，获利超 ¥20 亿。**这是捕捉一次性的错误定价，不可复制。**

**② 他自己归因于时代红利。**
在访谈中他表示，成功并非来自特殊策略，而是**日经指数快速上涨 + 日本放松管制带来的低佣金网络交易**。这是当事人自己的诚实归因，值得重视。

### 2.4 Nicolas Darvas — T2，Time 杂志四次核查

**记录**：约 $36,000 → $2,250,000，约 18 个月（1957–1959）。

**验证方式**：《Time》杂志在 1959-05-25 封面故事报道前**独立核查了四次**。在交易史上，由大型出版物做这种核查是很罕见的。

#### Box Theory（箱体理论）

| 步骤 | 规则 |
| --- | --- |
| ① 前提 | 股票**先创新高** |
| ② 形成箱体 | 从高点回落后，**连续至少 3 天**不突破该箱顶/箱底 |
| ③ 入场 | 价格**放量突破箱顶** |
| ④ 止损 | 随新箱体形成，**止损上移到每个新箱体的底部** |
| ⑤ 加仓 | 走出新箱体后可加仓 |

#### 他的执行方式本身就是优势

他是职业舞蹈演员，在全球巡演，**只能靠电报交易**：券商每天发电报送收盘价，他在酒店分析后发电报下单。

这个限制**强制**他做到：
- 只看**收盘价**，不被盘中噪音干扰
- 所有订单**预先定义**，无法临时冲动改单
- 天然低频，成本极低

#### 方法的两个明确缺陷（现代分析指出）

1. **"放量"从未被量化** —— 多少算放量？没有定义就无法回测。
2. **没有市场环境过滤器** —— 在震荡市会被反复假突破打损。

### 2.5 Tim Grittani — T4，平台逐笔追踪

**记录**：$1,500 → 超过 $13.5M 交易利润。CNN 于 2013-12-16 报道其"三年从 $1,500 到 $100 万"。

**验证方式**：Profit.ly 平台逐笔记录（用户名 kroyrunner），公开可查。

**⚠️ 证据降级理由**：其导师 Timothy Sykes 的网站现在明确标注这些数字"**unverified**（未经独立验证）"并附 FTC 免责声明。平台与培训业务存在商业利益关联，因此列为 T4 而非 T2。

#### 交易方式

- **低价股（penny stock）形态日内交易**
- 用 K 线形态 + 成交量信号识别可重复的价格行为
- 同时做**突破做多**与**拉高出货后做空**
- 核心是**极快地砍掉亏损**

#### 同样重要的起步事实

- 他**先爆掉了最初的 $1,500**，靠暑期打工重新入金
- 向家人借了 $11,000 只为**开多个账户绕开 PDT 规则**，但约定只交易自己的 $1,500
- 用了**九个月**才找到稳定性

## 三、一个必须看的反面案例：FTC 处罚

**Warrior Trading / Ross Cameron**，2022 年 4 月，美国联邦贸易委员会（FTC）。

这个案例之所以必须看，是因为它**精确区分了两件常被混为一谈的事**。

**FTC 认定的事实**（原始新闻稿）：
- Warrior Trading 在广告中展示其 CEO 的交易结果，宣称策略"可盈利"且"**可规模化（scalable）**"
- 广告用语包括："学习我如何在 45 天内用 3 个简单策略赚到 $101,280.47 的**已验证利润**"
- **FTC 诉状指出：绝大多数客户账户实际上是亏钱的**，许多人在付了几千美元学费之外又亏了几千美元
- 2018–2021 年，该公司靠卖课程赚了数千万美元

**处罚结果**：
- 支付 **$300 万** 消费者退款
- **禁止**再做无依据的收益宣称
- 禁止暗示购买者无论背景、资金量、投入时间都能成功
- 委员会投票 4-0 通过

**这个案例的关键区分**：

> **"他自己赚到了钱"** 与 **"你按他的方法也能赚到钱"** 是两个完全独立的命题。
>
> FTC 处罚的是**第二个命题**，不是第一个。一个人可以既是真实盈利的交易员，又在"可复制性"上做了虚假宣传。

**因此评估任何"可证实"案例时，必须追问**：这个记录证明的是"他做到了"，还是"这个方法可复制"？前者常见，后者极少被证明。

## 四、残酷的数学：钱到底是在哪几年赚的

这一节是整份研究里最应该记住的部分。

### 4.1 Kullamägi：94% 的钱来自 2 年

从他的公开税单直接算：

| 区间 | 已实现所得 | 占比 |
| --- | --- | --- |
| 2014–2019（6 年） | 约 $5M | **6%** |
| **2020–2021（2 年）** | **$75M** | **94%** |
| 2014–2021 累计 | $80M | 100% |

**六年打底，两年爆发。** 2020–2021 正是疫情后成长股动量最极端的时期。

### 4.2 其他人的时间集中度

| 交易员 | 主要收益窗口 | 当时市场环境 |
| --- | --- | --- |
| Zanger | 1998–1999（18 个月） | 互联网泡沫最疯狂阶段 |
| Darvas | 1957–1959（18 个月） | 战后牛市 |
| BNF | 2000–2008 | 日经上涨 + 日本交易管制放松 |
| Kullamägi | 2020–2021 | 疫情后动量泡沫 |

**没有一个人的主要收益是均匀分布在十年里的。**

### 4.3 复利算术的现实检验

| 案例 | 倍数 | 时长 | 折算年化 |
| --- | --- | --- | --- |
| Darvas | 62.5× | 1.5 年 | 约 **1,470%/年** |
| BNF | 约 11,250× | 8 年 | 约 **220%/年** |
| Kullamägi | 约 21,000× | 约 10 年 | 约 **170%/年** |

**Darvas 的 1,470%/年 是一个强烈的信号**：这种数字几乎必然意味着**极端顺风的单一市场状态 + 高杠杆**，而不是可持续的常态能力。

### 4.4 回吐同样惊人

| 交易员 | 回撤 |
| --- | --- |
| Zanger | 泡沫破裂后约 **−87%** |
| Kullamägi | 2022 年约 **−$60M**（税单 −$26M 已实现） |

**收益和回撤是同一枚硬币。** 能产生 200%/年的风险敞口，也能产生 −87%。

## 五、共同结构：他们真正做对的五件事

把五个人合起来看，骨架惊人地一致。

### ① 都先经历多年失败或平台期

| 交易员 | 起步代价 |
| --- | --- |
| Kullamägi | 2011–2013 **爆仓 3 次**，第四次才成 |
| Grittani | 先爆掉 $1,500，打工重新入金，**9 个月**才稳定 |
| Darvas | 1952 入场，**约 5 年**摸索才形成箱体法 |
| Zanger | 交易约 **20 年**后才出现那次爆发 |

**"小资金做大"的故事里，被省略的永远是前面那几年。**

### ② 入场点贴着失效位，止损极小

- Kullamägi：止损 = 突破当日低点
- Zanger：跌回突破点下 $3–5 就走
- Darvas：止损 = 箱体底部
- BNF：严格风控

**小止损不是靠"胆子大设得近"，而是入场位置本身就选在结构失效点旁边。**

### ③ 接受低胜率，靠赔率活着

Kullamägi 胜率 **25–30%**，即 10 笔亏 7–8 笔。这能成立的唯一原因是**赢家远大于输家**。

如果你的胜率 30% 但盈亏比只有 1:1，数学期望必为负。

### ④ 只在特定环境出手，其余时间空仓

- Kullamägi：大盘在 10/20 日均线下转现金（**他 2022 年违反此规则，代价 $60M**）
- Zanger：规则 7 明确警告市场大涨后持股脆弱
- BNF：只在极端超跌时出手

### ⑤ 让赢家跑，快速砍掉不动的

- Zanger 规则 5：**最强的持有最久，迟滞的迅速卖掉**
- Kullamägi：先减 1/3–1/2，剩余用均线移动止损
- Darvas：止损随新箱体不断上移

## 六、不可移植的部分

诚实地说，以下这些**学不来**：

| 因素 | 说明 |
| --- | --- |
| **时代红利** | Zanger 的 1999、Kullamägi 的 2020–21、BNF 的日本管制放松，都是**一次性的市场结构窗口** |
| **一次性事件** | BNF 的 J-Com 是别人的操作失误，不可复制 |
| **幸存者位置** | 我们看不到同期用同样方法爆仓消失的人 |
| **个人执行力** | Kullamägi 自己都承认 2022 年**没遵守自己的规则** |
| **杠杆结构** | Zanger 用融资、Darvas 疑似重仓，后果是 −87% 回撤 |
| **市场差异** | 他们交易股票/期货，有涨跌停、有休市；OKX 永续 7×24、无熔断、有资金费率与强平 |

**最关键的一条**：FTC 案例已经证明，"**他做到了**"不等于"**你能做到**"。任何培训或策略宣传若把前者当作后者的证据，就是逻辑跳跃。

## 七、对 PULSEDESK 的启示

**说明：以下为分析与提案，本轮未实施任何策略变更。**

### 7.1 这些方法与项目现有能力的对应

| 冠军做法 | 项目现状 | 可否验证 |
| --- | --- | --- |
| 突破当日低点止损 | `priceAction.ts` 已有信号棒外一 tick + 结构止损 | ✅ 已实现 |
| 低胜率 + 高赔率 | 回放已按 R 计量，含成本对账 | ✅ 可统计 |
| 市场环境过滤 | 有 EMA 斜率背景判断，但**多为警告而非硬门槛** | ⚠️ 需升级 |
| 让赢家跑（移动止损） | 有五种出场方案 | ⚠️ 缺"延伸计数"类分批 |
| 只在特定环境出手 | 时段标注已完整 | ⚠️ 未作为生成候选的前置条件 |
| 多年样本、极端值依赖 | 已有审计快照表 | ⚠️ 缺"利润集中度"统计 |

### 7.2 三个最值得加的统计（不改策略，只加观测）

基于本次研究，最有价值的不是抄某个入场法，而是**加上能揭穿自己的统计**：

**① 利润集中度**
> Kullamägi 94% 收益来自 2 年；Kell 回测中 10 笔贡献 92% 利润。
>
> 项目应统计：**前 N 笔交易贡献了总利润的百分之多少**。如果去掉最好的 5 笔后策略就不赚钱，说明它依赖异常值，样本外极不稳定。

**② 分年份/分环境的收益分布**
> 不要只看总体胜率与平均 R，要看**收益是否集中在少数时段**。这直接对应"时代红利"风险。

**③ 环境过滤器的反事实统计**
> 统计"如果不遵守环境过滤会怎样"。Kullamägi 的 −$60M 就是这个数字的现实版本。

### 7.3 明确不建议做的

- ❌ 不要因为看到 $5,000→$100M 就提高杠杆或仓位
- ❌ 不要把股票市场的融资结构直接套到 7×24 永续
- ❌ 不要把 J-Com 这类一次性事件当作策略
- ❌ 不要在未经样本外与成本压力验证前，把任何冠军规则设为默认执行
