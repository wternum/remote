## 一、先给结论

### 1.1 最重要的五句话

1. **双顶/双底首先是价格结构，不是 RSI/MACD 那种单一数值指标。**
   核心对象是：前趋势、两个极值、中间颈线、形态高度、时间间隔、收盘确认。

2. **“看见两个顶/底”不等于形态完成。**
   经典确认通常要求价格收盘越过颈线：双顶收盘跌破两顶之间低点；双底收盘站上两底之间高点。

3. **“二次测试拒绝”和“颈线突破后回踩”是两种不同交易。**
   前者发生在形态完成前，赔率可能更好但失败率更高；后者发生在确认后，确认更强但可能错过不回踩的行情。

4. **指标分工比指标数量重要。**
   价格结构负责“在哪里观察”；成交量/订单流负责“参与是否支持”；RSI/MACD 负责“动量是否衰减”；ATR/成本负责“是否值得做”；VWAP/Volume Profile 只是位置参考。

5. **当前项目已有价格结构、ATR、量能、真实 taker Delta/CVD、颈线生命周期；但没有把 RSI/MACD/VWAP/Volume Profile 自动接入双顶双底评分。**
   指标库里能添加这些指标，不等于它们已经参与信号过滤。

### 1.2 一眼分类

| 你现在看到的东西 | 正确名称 | 能不能直接交易 |
| --- | --- | --- |
| 两个相近高点/低点 | 候选双顶/双底 | 不能，仅候选 |
| 第二次测试出现拒绝 K | 二次测试拒绝候选 | 可作为激进协议，但未完成经典确认 |
| 收盘越过颈线 | 形态确认/破位 | 可进入突破协议评估 |
| 破位后回到颈线并守住/受阻 | 突破后回踩/反抽 | 可进入回调协议评估 |
| RSI 背离 | 动量衰减证据 | 不能单独交易 |
| 放量 | 参与度上升 | 必须结合收盘位置与方向 |
| 大单/CVD | 主动成交方向/累计 | 不能证明机构身份或未来必涨必跌 |

## 二、证据来源与可信度

### 2.1 本文使用的证据等级

| 等级 | 来源类型 | 用途 | 限制 |
| --- | --- | --- | --- |
| A | 同行评审论文 / NBER 正式工作论文 | 判断“形态是否有信息量”“成本是否改变结论” | 不直接等于 OKX 5m 可盈利 |
| B | Bulkowski 形态研究原站 | 学习经典定义、颈线确认、回踩/反抽、测量目标 | 主要是美股日线、人工分类、perfect trades，不能移植胜率 |
| C | StockCharts / TradingView / Sierra Chart 官方文档 | 指标定义与计算口径 | 教学定义不等于策略优势 |
| D | 当前项目源码与测试 | 判断项目真实实现 | 只能证明代码做了什么，不能证明盈利 |
| E | 无来源 SEO 文章 | 不采用 | 常见“60–70% / 88% 成功率”无可复核样本 |

### 2.2 关键文献到底说了什么

**Lo, Mamaysky & Wang (2000), Journal of Finance / NBER w7613**
- 用非参数核回归自动识别技术形态，比较条件收益分布与无条件收益分布。
- 结论是若干形态在美股日线样本中提供**增量信息**。
- **不是**“双顶双底必胜”，也不是 OKX 永续 5m 回测。
- 对本项目的意义：形态必须可重复、可因果识别，不能靠事后肉眼挑图。

**Bulkowski, Encyclopedia of Chart Patterns / ThePatternSite**
- 双顶/双底必须等颈线收盘确认；未确认只是 twin peaks/bottoms。
- 区分 Adam（尖）与 Eve（圆宽）组合；不同变体统计不同。
- 回踩/反抽常见，但出现回踩并不保证更强；其样本中回踩可能降低最终平均涨跌幅。
- 浅回踩、守住确认位，比深跌回确认位更值得研究。
- **不能把其美股日线百分比当作 BTC/ETH/SOL 5m 胜率。**

**Svogun & Bazán-Palomino (2022), Journal of International Financial Markets, Institutions and Money**
- 测试 69 条均线/突破规则，1 分钟与日线，5 种加密货币，2016–2021。
- 交易成本在 1 分钟频率上显著改变盈利性，在日线频率上影响小得多。
- 对本项目的意义：5m/15m 双顶双底必须先看成本余量，再谈指标叠加。

**Cont, Kukanov & Stoikov (2014), Journal of Financial Econometrics**
- OFI 来自订单簿事件：限价单、撤单、市价单造成的最佳买卖队列变化。
- **不是**单纯 taker buy−sell。
- 对本项目的意义：项目当前是 taker Delta/CVD，不能冒称完整 OFI。

## 三、双顶双底不是单一指标，而是一套状态机

### 3.1 经典结构定义

**双顶（M）**
1. 前面有一段上涨。
2. 第一个高点 `P1`。
3. 回调形成中间低点 `N`，即颈线。
4. 第二个高点 `P2` 接近 `P1`，可略高/略低，但必须在容差内。
5. 价格收盘跌破 `N`，经典双顶确认。
6. 跌破后反抽 `N` 受阻，是突破后回调交易。

**双底（W）**
1. 前面有一段下跌。
2. 第一个低点 `T1`。
3. 反弹形成中间高点 `N`，即颈线。
4. 第二个低点 `T2` 接近 `T1`。
5. 价格收盘站上 `N`，经典双底确认。
6. 站上后回踩 `N` 守住，是突破后回调交易。

### 3.2 状态机

```text
前趋势
  ↓
第一极值 P1/T1
  ↓
中间颈线 N
  ↓
第二极值 P2/T2 接近第一极值
  ↓
候选形态 candidate
  ├─ 二次测试拒绝 → 激进反转候选（未经典确认）
  ├─ 外侧极值被有效突破 → 原反转假设失效 / 可能延续
  └─ 收盘越过颈线 → 经典确认
        ↓
     突破跟随 / 等待回踩
        ├─ 回踩守住 → 回调入场候选
        ├─ 收盘收回颈线内 → 假突破 / 失败
        └─ 超时未回踩 → 过期，不追旧信号
```

### 3.3 颈线不是随便画的线

- 双顶颈线：两顶之间的**回调低点**。
- 双底颈线：两底之间的**反弹高点**。
- 如果中间有多个小波动，工程上必须固定规则：取最低 low / 最高 high，或取确认摆动点。
- 项目当前在候选阶段会更新中间极值，二次测试时冻结颈线；这是为了避免事后挪线。

### 3.4 测量目标

经典测量目标：

```text
形态高度 H = |极值价格 − 颈线价格|
双底目标 = 颈线 + H
双顶目标 = 颈线 − H
```

但交易时不能只看这个公式：
- 实际入场可能在突破后或回踩后，不在颈线。
- 最近阻力/支撑、前高前低、VWAP、POC 可能比测量目标更近。
- 目标必须扣除手续费、滑点、资金费率后仍有空间。
- 测量目标是参考，不是必达。

## 四、自动双顶双底指标通常怎么识别

### 4.1 常见算法

多数自动指标使用：

1. **Pivot High / Pivot Low**
   - 左侧 `L` 根、右侧 `R` 根确认局部极值。
   - 例如 `L=8, R=5`：一个低点必须比左侧 8 根低，且右侧 5 根没有更低，才在右侧第 5 根收盘后确认。

2. **ZigZag**
   - 用百分比或 ATR 阈值连接摆动点。
   - 末端未确认摆动可能随新价格变化。

3. **等高/等低容差**
   - 固定百分比，如 1–3%。
   - 或 ATR 容差，如 0.3–0.7 ATR。
   - 加密短线更适合 ATR/价格混合容差，因为不同币价与波动差异大。

4. **时间间隔**
   - 两顶/两底不能太近，否则只是噪音。
   - 也不能太远，否则关键位可能失效。

5. **颈线突破确认**
   - 盘中触碰、单根收盘、两根收盘、收盘加幅度缓冲，都是不同协议。

### 4.2 自动指标的两大陷阱

**陷阱 1：右侧确认延迟**
- `R=5` 在 5m 上意味着第一极值发生后至少 25 分钟才确认。
- 在 15m 上意味着 75 分钟。
- 如果指标把信号画回第一极值那根 K 线，看起来像提前预测，实际是事后确认。

**陷阱 2：重绘 / repaint**
- ZigZag 末端、未确认 pivot、盘中颈线突破都可能变化。
- 正确做法：只把已收盘且右侧确认完成的 pivot 当成历史事实；新事件可以推进状态，但不能倒改旧确认时间。

### 4.3 项目当前选择

项目 `patterns.ts` 使用因果 pivot：
- 左 8 / 右 5。
- 第一极值只有在右侧 5 根收盘后才存在。
- 二次测试需要收盘拒绝，或紧接下一根收盘确认。
- 不允许跨越历史缺口连接两个测试。

这是正确方向；代价是会漏掉一些 V 形或极快二测。

## 五、指标分层：哪些是核心，哪些只是辅助

### 5.1 分层表

| 层级 | 指标/变量 | 回答的问题 | 是否可单独入场 |
| --- | --- | --- | --- |
| 0 数据完整性 | confirm、时间连续、报价币成交额、tickSz | 数据能不能用 | 否 |
| 1 结构 | 前趋势、pivot、等高容差、颈线、高度、间隔 | 在哪里观察 | 否 |
| 2 确认 | 收盘越位、拒绝 K、影线、扫位收回 | 假设是否开始兑现 | 可作为触发协议 |
| 3 参与度 | RVOL、两腿量比、突破量、回踩量 | 参与是否支持 | 否 |
| 4 动量 | RSI 背离、MACD 柱/线背离 | 推动是否衰减 | 否 |
| 5 环境 | EMA20/50、HTF 关键位、ADX、时段 | 顺势还是逆势 | 否 |
| 6 波动/成本 | ATR、高度/ATR、止损距离、成本/风险 | 是否值得做 | 否决条件 |
| 7 微观成交 | taker Delta、CVD、OI、盘口快照、真 OFI | 主动成交/持仓是否支持 | 否，需价格触发 |
| 8 位置参考 | VWAP/AVWAP、Volume Profile POC/VAH/VAL | 附近是否有成交密集/成本区 | 否 |

### 5.2 最小可用组合

如果只允许保留最少指标：

```text
价格结构 + 颈线收盘确认 + ATR + 相对成交量 + 成本/风险过滤
```

如果数据质量足够，再加：

```text
真实 taker Delta / CVD（仅覆盖完整时）
```

RSI/MACD 是可选动量证据，不是必需。VWAP/Volume Profile 是位置背景，不是方向信号。

### 5.3 不要重复计票

以下指标高度相关，不能当成多个独立证据：

- RSI、MACD、Stochastic：都来自价格动量。
- Volume、OBV、MFI：都来自成交量/价格方向。
- Delta、CVD、taker ratio：同一逐笔主动成交的不同聚合。
- EMA20/50、趋势线、ADX：都描述趋势状态。

正确做法是按“证据家族”做消融实验，而不是堆 10 个指标投票。

## 六、逐个指标详解

### 6.1 价格结构：第一优先级

**看什么**
- 前趋势是否存在。
- 两个极值是否接近。
- 中间颈线是否清晰。
- 形态高度是否足够。
- 两测间隔是否合理。
- 是否收盘确认。

**为什么重要**
没有前趋势，双顶双底可能只是区间边缘；没有颈线确认，只是候选。

**项目实现**
- `priorMoveAtr=1.5`
- `minHeightAtr=2`
- `minGap=8`
- `lookback=288`
- 视觉层容差：`min(max(0.35ATR, 0.04%价格), 0.7ATR)`

### 6.2 ATR：波动标尺，不是方向指标

**公式**

```text
TR = max(H−L, |H−prevClose|, |L−prevClose|)
ATR = TR 的平均
```

项目 `atrSeries` 使用 14 期简单滚动平均，不是 Wilder 平滑。

**用途**
- 等高/等低容差。
- 颈线高度是否足够。
- 止损缓冲。
- 扫位深度。
- 突破是否过度远离颈线。
- 成本占风险比例。

**误用**
- ATR 高不代表要反转。
- ATR 低不代表安全；可能只是没空间。

### 6.3 相对成交量 RVOL

**公式**

```text
RVOL_t = Volume_t / mean(Volume_{t−20..t−1})
```

项目 `volMa` 不含当前 K，避免当前放量污染基准。

**用途**
- 第二腿是否缩量：支持衰竭。
- 测试 K 是否放量但价格未推进：吸收候选。
- 突破 K 是否放量：参与度支持。
- 回踩 K 是否缩量：抛压/买压减弱。

**项目阈值**
- 第二腿/第一腿单位量 ≤0.9：缩量支持。
- >1.1：放量反证。
- 确认 K ≥1.5×：放量。
- 突破确认量 ≥1.5×，或 ≥1.2× 且真实成交同向。
- 回踩确认量 ≤0.9× 突破确认 K。

**注意**
这些是工程阈值，不是文献证明的 universal constants。

### 6.4 成交量形态：第二测试缩量不是唯一正确路径

经典教学常说：
- 双顶第二顶缩量 → 买盘衰竭。
- 双底第二底缩量 → 卖盘衰竭。

但另一种有效路径是：
- 第二测试**放量刺破**后收盘收回。
- 这可能是恐慌/追单被对手方承接。

因此不能机械规定“第二测试必须缩量”。应区分：

| 情况 | 解释 |
| --- | --- |
| 缩量接近前高/前低 | 推动不足 |
| 放量刺破但收回 | 推进失败 / 吸收候选 |
| 放量收盘站稳外侧 | 更像真突破 |
| 缩量突破 | 证据弱，需要跟随或回踩 |

### 6.5 K 线拒绝：影线与收盘位置

**公式**

```text
range = H − L
closePos = (C − L) / range
bottomWick = (min(O,C) − L) / range
topWick = (H − max(O,C)) / range
```

双底看：下影线、收盘回到上半部、收盘离开支撑。
双顶看：上影线、收盘回到下半部、收盘离开阻力。

**项目实现**
- 拒绝收盘需离开关键位 `0.05ATR`。
- `closePos >= 0.5`。
- 阳线或下影线 ≥35%（底部坐标；顶部镜像）。
- 证据层影线 ≥35% 加分。

**误用**
长影线单独不是入场；必须发生在关键位，并有后续确认。

### 6.6 RSI：动量背离，不是买卖按钮

**公式**

```text
RS = avgGain / avgLoss
RSI = 100 − 100/(1+RS)
```

常见 14 期，Wilder 平滑。

**双顶用法**
- 价格第二顶等高或略新高。
- RSI 第二顶低于第一顶。
- 解释：价格推到前高，但动量没有跟上。

**双底用法**
- 价格第二底等低或略新低。
- RSI 第二底高于第一底。

**关键限制**
- 强趋势中 RSI 可以长期超买/超卖。
- 背离可以连续出现多次而价格不反转。
- 必须用相同 pivot 对齐价格和 RSI，不能随便挑两个点。
- 70/30 是背景，不是触发。

**项目现状**
- Vela SDK/指标库有 RSI。
- 双顶双底评分 **没有** RSI 因子。

### 6.7 MACD：动量差值，滞后但可看衰减

**公式**

```text
MACD = EMA12 − EMA26
Signal = EMA9(MACD)
Histogram = MACD − Signal
```

**用途**
- 双顶：价格新高/等高，MACD 或柱状图峰值降低。
- 双底：价格新低/等低，MACD 或柱状图谷值抬高。
- 柱状图缩短可提示推动减速。

**限制**
- MACD 是均线差，滞后。
- 不适合单独做 5m 反转触发。
- 与 RSI 同属动量家族，不应重复计票。

**项目现状**
- 指标库有 MACD。
- 双顶双底评分 **没有** MACD 因子。

### 6.8 EMA20/50：趋势背景

**用途**
- 判断二次测试是否逆强趋势。
- 双底若发生在上升 EMA 回调中，可能是牛旗。
- 双顶若发生在下降 EMA 反弹中，可能是熊旗。
- 突破后回踩 EMA + 颈线重合，可作位置参考。

**项目实现**
- `trendExhaust = (EMA20−EMA50)/ATR` 反向归一。
- 原引擎有 `trendBlock` 硬屏蔽；当前覆盖层 `paramsFor` 设为 50，等于关闭硬屏蔽，改由评分处理。

**误用**
EMA 金叉死叉不是双顶双底确认。

### 6.9 ADX：趋势/震荡背景，可选

**用途**
- ADX 低：震荡，双顶双底更可能是区间边缘。
- ADX 高：强趋势，逆势双顶双底风险更高。

**限制**
- ADX 滞后，不指方向。
- 项目当前 M/W 评分没有 ADX。

### 6.10布林带：压缩/扩张背景，可选

**用途**
- 颈线附近带宽收缩后扩张，可辅助突破。
- 触上轨/下轨不是双顶双底确认。

**项目现状**
- 指标库有 Bollinger Bands。
- M/W 评分未使用。

### 6.11 OBV：粗粒度量能累计

**公式**

```text
OBV_t = OBV_{t−1} + sign(C_t−C_{t−1}) × Volume_t
```

**用途**
- 价格第二顶，OBV 未新高：量能不支持。
- 价格第二底，OBV 未新低：卖压不支持。

**限制**
- 只按 K 线收盘方向分配整根成交量，不是真实主动买卖。
- 与 RVOL/量比同属成交量家族。

**项目现状**
- SDK 有 `on-balance-volume`。
- M/W 评分未使用。

### 6.12 VWAP / Anchored VWAP：成交成本参考

**公式**

```text
VWAP = Σ(price × volume) / Σ(volume)
```

**用途**
- 双底突破后回踩颈线，同时回踩 session VWAP：位置重合。
- 双顶反抽颈线，同时反抽 VWAP：阻力重合。
- 可锚定第一极值、颈线突破 K、事件 K。

**限制**
- 必须有准确 price×volume；项目 fallback 估算额不能当精确 VWAP。
- 加密 24/7，必须定义锚点：UTC 日、时段、事件。
- VWAP 不是支撑阻力保证。

**项目现状**
- 指标库有 VWAP。
- M/W 评分未使用。

### 6.13 Volume Profile / POC / VAH / VAL：成交密集区

**定义**
- POC：区间内成交量最大的价格。
- VA：包含指定比例成交量的价格区，常见 70%。
- VAH/VAL：价值区上下沿。
- HVN/LVN：高/低成交节点。

**用途**
- 双底颈线与 POC/VAH 重合，突破后回踩更有参考。
- 双顶颈线与 POC/VAL 重合，跌破后反抽更有参考。
- 目标先看最近 HVN/POC，而不是只看测量目标。

**限制**
- 需要按价格分箱的成交量；仅 OHLCV 不够精确。
- TradingView 官方说明 VP 用更低周期数据，且 up/down volume 不等于 buy/sell taker volume。
- Visible Range Profile 会随缩放变化，不能直接当稳定回测因子。

**项目现状**
- 指标库有 VPVR。
- 信号引擎没有逐价 volume profile 数据管线。

### 6.14 Taker Delta：项目已有的真实成交证据

**公式**

```text
Delta = takerBuyQuote − takerSellQuote
Ratio = Delta / (takerBuyQuote + takerSellQuote)
```

**用途**
- 双顶测试：主动买入强但价格收回 → 推进失败候选。
- 双底测试：主动卖出强但价格收回 → 承接候选。
- 突破 K：Delta 与突破方向一致 → 参与支持。
- 回踩 K：Delta 不强烈反向 → 回踩质量较好。

**项目覆盖门槛**
- tape：聚合额 / K 线报价币成交额在 85%–110%。
- rubik：95%–110%。
- 估算成交额不能验证覆盖。

**限制**
- 不是订单簿 OFI。
- 不知道 passive 对手方身份。
- 大单不等于机构。

### 6.15 CVD：连续累计 Delta

**公式**

```text
CVD_t = CVD_{t−1} + Delta_t
```

**用途**
- 价格第二顶，CVD 未同步新高。
- 价格第二底，CVD 未同步新低。

**硬要求**
- 同一锚点/reset。
- 两次测试之间每根 K 线连续真实覆盖。
- 缺任一根不能拼接近似值。

**项目现状**
- `readMwEvidence` 要求连续覆盖，否则 `cvdRatio=null`。
- 旧引擎 `readSecondTest` 有覆盖率加权近似路径；两者口径不同，不能混用。

### 6.16 盘口快照 vs 真 OFI

| 名称 | 数据 | 能回答 |
| --- | --- | --- |
| Book imbalance | 某时刻 bid/ask 挂单量差 | 当前显示队列不对称 |
| True OFI | bid/ask 报价与队列变化事件 | 一段时间内订单簿供需失衡 |

项目当前只有 API 盘口快照因子，没有完整 `books` 增量 OFI 管线。不能把快照差称为 OFI。

### 6.17 OI / Funding：衍生品背景

**OI**
- 持仓量增加说明总持仓扩张，不能识别多空身份。
- 价格冲高 + OI 增加：可能有新仓追入，但不能说“新多被套”。
- 价格杀跌 + OI 增加：可能有新空追入，但不能说“新空被套”。

**Funding**
- 极端正 funding：多头拥挤背景。
- 极端负 funding：空头拥挤背景。
- 不是双顶双底确认。

项目有 OI 因子；funding 在行情接口中展示，但未作为 M/W 核心确认。

## 七、三种“回调交易”必须分开

### 7.1 协议 A：二次测试拒绝（形态完成前）

**位置**
第二个顶/底附近，颈线尚未突破。

**看什么**
1. 前趋势存在。
2. 第二极值接近第一极值。
3. 第二腿缩量或动量衰减，或放量刺破后收回。
4. 拒绝 K / 下一根确认 K。
5. 止损在第二极值外侧。
6. 第一目标通常是颈线。

**优点**
- 入场靠近失效位，止损小。
- 如果后来颈线突破，赔率好。

**缺点**
- 形态未经典确认。
- 可能只是趋势中的暂停，随后继续原趋势。

**项目对应**
- 视觉层：`patterns.ts` 二次测试拒绝。
- 执行层：`db_reject/dt_reject`。
- `touch` 模式更激进：关键位挂单，同根触及即假设成交。

### 7.2 协议 B：颈线突破后回踩/反抽（形态确认后）

**位置**
颈线已经被收盘突破，价格回到颈线附近。

**双底回踩**
1. 收盘站上颈线。
2. 突破有量能/跟随支持。
3. 价格回到颈线区。
4. 回踩量缩，收盘守住颈线上方。
5. 入场触发：回踩确认 K 高点上方，或收盘确认后协议。
6. 止损：回踩低点/颈线下方缓冲。
7. 目标：测量目标或最近阻力。

**双顶反抽**
镜像：收盘跌破颈线 → 反抽颈线 → 放量下跌/缩量反抽 → 收盘受阻 → 做空触发。

**优点**
- 形态已确认。
- 入场比追突破更靠近颈线，止损更清晰。

**缺点**
- 强突破可能不回踩，直接错过。
- 回踩本身可能演变成假突破。
- Bulkowski 样本中，出现回踩不一定提高最终涨跌幅；它改善的是入场位置，不是保证结果。

**项目对应**
- `scenario.ts/evaluateLine`：两根收盘越位、首次触带、收盘守住、失败、过期。
- `mwStory.ts`：`break-wait → break-retest → break-held`。
- 质量门槛：回撤 ≤61.8%，回踩量 ≤0.9× 突破确认 K。

### 7.3 协议 C：双底/双顶后的更高低点/更低高点（Brooks 式）

**位置**
双底已经形成并向上运动后，再次深回调但不破前低，形成更高低点；双顶镜像。

**看什么**
- 原趋势线/通道是否被打破。
- 是否测试原极值。
- 回调是否两段。
- 是否出现 H2/L2 信号棒。
- 入场在信号棒外一 tick，止损在结构外侧。

**与协议 B 的区别**
- B 回踩的是**颈线**。
- C 回踩的是**双底/双顶后的趋势结构**，可能远离颈线。

**项目现状**
- `priceAction.ts` 有 H1/H2 研究层。
- 未与 M/W 颈线回踩自动合并成同一交易协议。

## 八、突破交易：看什么、怎么确认、怎么防假突破

### 8.1 突破的四个层级

| 层级 | 事实 | 强度 |
| --- | --- | --- |
| 盘中刺破颈线 | 仅触碰 | 最弱 |
| 单根收盘越过颈线 | 初步确认 | 中 |
| 收盘越过 + 幅度缓冲 | 减少噪音 | 较强 |
| 两根收盘越过 + 量能/跟随 | 项目视觉层协议 | 更强但更慢 |

### 8.2 突破质量指标

1. **收盘位置**
   - 双底突破 K 应收在颈线上方，最好上半部。
   - 双顶跌破 K 应收在颈线下方，最好下半部。

2. **突破幅度**
   - 太近：噪音。
   - 太远：追高，止损宽，回踩风险大。
   - 项目执行引擎拒绝突破收盘超过形态高度 50% 的追价。

3. **RVOL**
   - ≥1.5× 均量：项目视为放量。
   - 1.2–1.5×：需要真实成交同向。
   - <1.2×：弱突破，观望。

4. **跟随 K**
   - 突破后下一根继续同向收盘，比单根大阳/大阴更可靠。

5. **真实 Delta**
   - 突破方向主动成交占优，支持参与度。
   - 但 Delta 同向不等于必涨；价格收盘仍是主确认。

6. **距离最近目标的空间**
   - 突破后如果马上碰到前高/POC/VAH，赔率可能不足。

### 8.3 假突破识别

假突破常见组合：
- 盘中突破，收盘收回。
- 单根突破，下一根立刻反向。
- 放量突破但价格不继续。
- 突破后回踩跌回/涨回颈线内侧超过缓冲。
- 外侧关键位被突破，原双顶/双底假设失效。

**项目处理**
- `evaluateLine`：收盘回到位内超过 0.2ATR → `failed`。
- `mwStory`：失败后只给反向候选，不自动下单。
- 关键位外侧突破会暂停原形态目标。

### 8.4 突破入场协议对比

| 协议 | 触发 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 盘中 stop 单 | 颈线外一 tick | 最早 | 假突破多 |
| 单根收盘确认 | 收盘越过颈线 | 平衡 | 仍可能次日收回 |
| 两根收盘确认 | 连续两根越过 | 更稳 | 更慢，入场更远 |
| 突破后回踩 | 回踩守住再触发 | 止损近 | 可能错过 |
| 项目执行层 break | 单根收盘 + K 线质量 | 可回测 | 默认 `enableBreak=false` |

**重要：当前项目默认没有开启执行层颈线突破交易。**
视觉层有颈线生命周期研究，不等于执行层默认交易突破。

## 十、当前项目代码到底实现了什么

### 10.1 数据层

| 能力 | 状态 | 代码 |
| --- | --- | --- |
| OKX K 线 REST/WS | 有 | `okxProvider.ts`, `server/okx.ts` |
| confirm 收盘标记 | 有 | `okxCandles.ts`, `closedCandles` |
| 报价币成交额 | 有，优先 `volCcyQuote` | `okxVolume.ts` |
| 估算成交额标记 | 有 | `volumeSource` |
| 真实 taker tape/rubik | 有 | `quant/flow.ts` |
| 完整订单簿 OFI | 无 | — |
| 逐价 footprint | 无 | `FlowTrade` 不保留 px |

### 10.2 形态层

`src/vela/signals/patterns.ts`：
- 因果 pivot：左 8 / 右 5。
- 两测间隔 ≥8 根。
- 颈线高度 ≥2ATR。
- 前趋势 ≥1.5ATR。
- 视觉容差：`min(max(0.35ATR, 0.04%价格), 0.7ATR)`。
- 扫位深度容许 0.5ATR。
- 二测拒绝或下一根确认。

`remote/.../engine.ts` 执行层：
- 几何类似，但容差是 `max(0.35ATR, 0.04%价格)`，**没有 0.7ATR 上限**。
- 因此视觉层与执行层在高波动下可能不完全一致；本轮未改参数。

### 10.3 证据层

`src/vela/signals/evidence.ts`：
- 第二腿单位量比。
- 测试/确认 K RVOL。
- 影线、扫位、收盘收回。
- 真实 taker 观察，缺覆盖不补。
- 连续 CVD，缺任一根不计算。
- 吸收候选：量比≥2、推进侧 Delta 强但价格未跟随。

### 10.4 颈线生命周期

`src/vela/signals/scenario.ts`：
- 首根收盘越位 >0.2ATR：pending。
- 第二根连续收盘越位：broken。
- 等待回踩 48 根；触带后 12 根观察窗。
- 收盘回到位内 >0.2ATR：failed。
- 回踩质量：回撤≤61.8%，量≤0.9×突破确认 K。

### 10.5 执行层

`remote/.../engine.ts` + `src/lib/engine.ts` + `src/quant/scan.ts`：
- 默认 `entryMode='limit'`，`enableBreak=false`。
- 覆盖层 `runScan` 同时生成 confirm/touch 两轨。
- `confirm` 在覆盖层里是拒绝 K 确认后**下一根开盘市价**，不是信号棒外一 tick stop。
- `touch` 是关键位挂单，同根触及假设成交。
- 成本假设：taker 0.05%/边，滑点 0.01%/边。
- 同根止盈止损先后不明时先算止损。

### 10.6 指标库

Vela SDK 中存在：
- RSI、MACD、OBV、VWAP、VPVR、Bollinger、ATR 等。
- 指标库可添加它们到图表。

但：
- 双顶双底评分没有 RSI/MACD/OBV/VWAP/VPVR 因子。
- `pulse.double` 在目录描述里有元数据，但当前源码/SDK 检索未发现注册；不能把它当成已实现指标。

### 10.7 当前 UI 真相

- `runtime.ts` 中 `MARKERS_ENABLED=false`：主图 M/W 画布标记当前下线。
- 当前右侧侧栏主要是时段调度台，不是完整 M/W 详情列表。
- 因此“代码里有 M/W 研究模块”不等于“用户当前图表已经显示所有 M/W 标记”。

### 10.8 本轮修正

- `tests/orderflow.test.ts` 原断言期待旧文案 `诱多·扫损收回`；代码已改为更准确的 `诱多·扫位收回候选`。本轮只更新测试断言，不改策略。
- 修正 `src/vela/signals/README.md` 中与当前代码不符的状态描述。

## 十一、5m / 15m 的使用边界

### 11.1 周期分工建议

| --- | --- |

- 双顶双底在 5m 上必须特别检查：目标空间 / 止损距离 / 成本。

### 11.3 参数不是优化结果

当前参数：
- L8/R5、minGap8、height2ATR、RVOL20、ATR14。

- 任何调整必须做样本外与成本压力测试。

## 十二、验证方案：如何判断一个指标真的有用

### 12.1 消融实验

固定同一套形态候选和出场协议，比较：

1. 仅价格结构。
2. 价格 + RVOL。
3. 价格 + RVOL + RSI 背离。
4. 价格 + RVOL + 真实 Delta。
5. 价格 + RVOL + Delta + 回踩质量。
6. 价格 + VWAP/POC 位置过滤。

每次只加一个家族，避免重复计票。

### 12.2 必须报告的指标

- 样本数 n。
- 真实成交覆盖率。
- 未触发 / 过期 / 路径不明数量。
- 成本后平均 R。
- 盈利因子。
- 最大回撤。
- 目标触达率。
- 回踩发生率。
- 错过不回踩强突破的比例。
- 去掉最好 5 笔后的结果。

### 12.3 防过拟合

- 时间序列切分，不随机打乱。
- 标签终点跨越训练/测试边界要 purge/embargo。
- 测试集冻结后再调参。
- 费用/滑点 ×2 压力测试。
- 分 BTC/ETH/SOL、5m/15m、时段、趋势/震荡分层。

### 12.4 什么时候才接入 UI

一个指标只有满足：
1. 数据口径清楚。
2. 缺失时不伪造。
3. 样本外有增量。
4. 成本后仍有效。
5. 不重复已有证据。

才应该进入双顶双底评分或硬过滤。否则只作为图表参考。

## 十三、常见错误

1. **看见 M/W 就交易**：没有颈线确认只是候选。
2. **第二顶放量就一定是假突破失败**：放量滞涨也可能是吸收候选；放量站稳外侧才是突破。
3. **RSI 超买就做空双顶**：强趋势可以长期超买。
4. **MACD 金叉就买双底**：滞后且可能只是反弹。
5. **回踩一定更安全**：回踩可能变成假突破；不回踩也可能直接走。
6. **大单=机构**：公共数据没有账户身份。
7. **CVD 绝对值高就买**：必须看局部变化、锚点和覆盖。
8. **Volume Profile 的 up/down volume 是主动买卖**：不是，它是 K 线方向分类。
9. **ZigZag 末端拐点可实时交易**：未确认会重绘。
10. **把美股日线成功率套到 OKX 5m**：市场、周期、成本、杠杆都不同。
11. **指标越多越可靠**：相关指标重复计票会制造虚假置信。
12. **视觉层有标记就等于执行层交易**：项目当前两者分离，且主图标记下线。
