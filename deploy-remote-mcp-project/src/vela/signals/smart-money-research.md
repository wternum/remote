# 关键位「聪明钱结构」观察：定义、适配与边界

> 本文配套实现 `src/quant/smartmoney.ts` 与侧栏类型「聪明钱结构」（`SignalType: smartMoney`）。
> 它把 SMC/ICT 中**有明确价格定义**的部分做成可复核的图表标注，**不**宣称机构身份、真实止损或胜率。

## 1. 先说结论

1. 「聪明钱」不是一个可被公开行情数据直接观测的实体。交易所公共接口只给成交、报价和持仓量，没有账户身份、委托意图或机构标签。
2. 因此本项目只标注**可验证的市场结构事实**：等高等低流动性被刺破后收回、收盘越位型结构事件、三根不重叠缺口、推进前的反向 K 线区域、价格处于区间溢价/折价一侧。
3. 这些要素在 SMC/ICT 里被称为 liquidity sweep、BOS/CHoCH、fair value gap、order block、premium/discount。名称沿用社区术语，判断标准写死在代码里，并全部可单测。
4. 五项命中数（`SMC n/5`）只是**结构条件计数**，用于排序与解释，不是概率、不是胜率、也不是回测收益。

## 2. 与现有 M/W 标注的适配位置

SMC 观察只附属于**已确认**的双顶/双底第二次测试（`scanAnnotationPatterns` 的输出），不独立发起信号：

- 锚点：`second`（第二测试）与 `idx`（收盘确认那根）。
- 关键位：`level`（第一极值），颈线：`neck`。
- 允许回看的区间：交易区间从 `first - 24` 到 `idx`；缺口/流动性只在 `second` 之前与确认前寻找。
- 因果性：所有窗口都以 `idx` 为上界，未来 K 线不会改写已确认标记（单测覆盖）。

这样做的原因：M/W 已经给出“关键位 + 方向 + 确认时点”；SMC 用来解释**这个关键位附近发生了什么结构**，而不是另外制造一套互相冲突的信号。

## 3. 五项判据（全部为工程参数）

| 证据 | 定义 | 数据要求 | 明确不声称 |
| --- | --- | --- | --- |
| 扫流动性后收回 | 关键位附近 `lookback=160` 根内至少 1 次触及（容差 `max(0.15 ATR, 0.04%价)`），本次第二测试刺破 ≥0.05 ATR 且确认收盘回到关键位内侧 | 价格 / ATR | 不知道被扫的是谁的止损，也不证明存在止损集群 |
| 结构事件同向 | 以已确认摆动位为基准，收盘越过即记为 BOS；与上一次越位方向相反记为 CHoCH；要求方向与本次反转一致 | 价格 / ATR | 不区分机构与散户，不含成交量确认 |
| 同向未回补缺口 | 三根 K 线不重叠，缺口高度 ≥0.1 ATR；多头缺口 = 第 3 根最低 > 第 1 根最高，空头镜像；回补状态限定在确认前 | 价格 | 不承诺缺口“必然回补”，不把缺口当支撑阻力实体 |
| 未回踩订单块候选 | 第二测试前最后一根反向 K 线（阴/阳），且到关键位的位移 ≥0.5 ATR；区间取该 K 线实体；确认前被回踩则标记 mitigated | 价格 / ATR | 不称“机构挂单区”，也不保证价格会在此反应 |
| 溢价/折价位置 | 确认收盘在当前交易区间（`first-24 → idx`）的分位；>50% 为溢价，<50% 为折价 | 价格 | 区间端点随数据变化，不是固定支撑阻力 |

可选的第六项「真实 taker 成交佐证」：

- 仅当 `second-6 → idx` 窗口的**逐笔覆盖 ≥95%** 时才输出；
- 只说明该窗口主动买卖差方向，与订单簿 OFI、冰山单、被动吸收无关；
- 没有覆盖时明确显示“—”，不会用 0 或近似值填充。

## 4. 与既有标注的关系

| 既有类型 | 与 SMC 的区别 |
| --- | --- |
| 关键位成交反应 | 逐根真实 B/S 与覆盖率；SMC 侧重结构，成交只作可选佐证 |
| 诱多 / 诱空候选 | 需要扫位收回 + 成交证据；SMC 的“扫流动性”允许只有价格结构，并明确标注来源 |
| CVD 背离 | 要求两次测试之间每根连续真实覆盖；SMC 不使用 CVD |
| 突破回踩 | 依赖已收盘突破与首次守住；SMC 的 BOS/CHoCH 只是结构事件，不生成入场建议 |

所有类型共享同一套开关与来源标签（`价格结构` / `真实逐笔`），关闭 SMC 不影响任何 M/W 或成交标注。

## 5. 权威来源与可迁移范围

1. **Michael J. Huddleston（ICT）**：order block、fair value gap、liquidity、BOS/CHoCH、premium/discount 等术语与方法论的原始普及来源，2010 年代起以公开内容传播。属个人教学体系，非同行评审研究。
2. **Richard Wyckoff（1910–1930）**：Composite Man、Spring / Upthrust、量价阶段；SMC 的“扫流动性”与 Spring 在价格形态上高度同源。见 Wyckoff 方法综述。
3. **Lo, Mamaysky & Wang (2000), NBER w7613**：把技术形态识别形式化并要求统计检验；本项目借鉴其“明确时点 + 可复现算法”的要求，但其样本为美股日线，不能外推为 OKX 5m 收益证明。
4. **Cont, Kukanov & Stoikov (2014)**：OFI 包含挂单新增/撤单/成交，**不是**成交买卖差；因此本项目不把 taker delta 称为 OFI。
5. **Osler (2005), NY Fed SR150**：外汇市场存在止损集群证据；但公共成交流没有止损委托信息，项目只能说“扫位收回候选”。
6. **公开回测证据**：第三方对 ICT 四项核心入场（订单块、FVG、扫流动性、OTE）在美股指数日线上的机械复现未发现统计显著的前瞻优势；另有平台统计显示 FVG 部分回补频率较高、而**单独**订单块反弹率不足一半。这些结论不能直接移植到 OKX 永续 5m，但足以说明：**不应把 SMC 标注包装成概率或必胜信号**。

> 结论：本项目把 SMC 定位为**可复核的结构描述层**。要升级成“预测信号”，必须先固定标签、horizon、purge/embargo，并做样本外与成本后检验；当前没有做，也不显示胜率。

## 6. 数据边界

- 只有 OHLCV + 公共逐笔 + 可选 rubik 统计；没有账户身份、盘口队列增量、逐价 footprint。
- rubik 接口不返回 CORS 头，浏览器不可直连；服务端扫描已接入并限制分页（taker 4 页、OI 2 页）。
- 历史逐笔回补深度有限（BTC 5m 通常仅覆盖最近数根），因此**大多数历史关键位的成交佐证为空**，这是有意的缺数据处理。
- 订单块是“推进前最后一根反向 K 线”的机械定义，不同教学者的定义并不一致；本项目不声称这是唯一正确版本。
